{%- comment -%} Renders one type of publication: the automatic list (_data/publications_auto.json, fetched from OpenAlex/ORCID/PubMed by scripts/fetch_publications.py) merged with the corrections in _data/publications.yml ("hidden" drops a DOI, a "manual" entry adds a work or replaces the automatic record with the same DOI). Emits nothing at all when the type has no entries, so empty sections vanish. Usage: {% include publication-list.html type="article" heading="Research articles" %} type: article | review | book-chapter | conference-paper | preprint {%- endcomment -%} {%- assign auto = site.data.publications_auto | default: empty -%} {%- assign manual = site.data.publications.manual | default: empty -%} {%- assign hidden = site.data.publications.hidden | default: empty -%} {%- comment -%} "|doi|doi|" lookup string of DOIs the automatic list must skip {%- endcomment -%} {%- capture skip -%}|{% for h in hidden %}{{ h.id | downcase | remove: "https://doi.org/" | remove: "doi:" }}|{% endfor %}{% for m in manual %}{% if m.doi %}{{ m.doi | downcase | remove: "https://doi.org/" }}|{% endif %}{% endfor %}{%- endcapture -%} {%- assign years = auto | map: "year" -%} {%- assign manual_years = manual | map: "year" -%} {%- assign years = years | concat: manual_years | uniq | sort | reverse -%} {%- capture items -%} {%- for y in years -%} {%- for p in manual -%} {%- if p.year == y and p.type == include.type -%}{%- include publication-item.html p=p -%}{%- endif -%} {%- endfor -%} {%- for p in auto -%} {%- if p.year != y or p.type != include.type -%}{%- continue -%}{%- endif -%} {%- capture key -%}|{{ p.doi | downcase }}|{%- endcapture -%} {%- if p.doi and skip contains key -%}{%- continue -%}{%- endif -%} {%- include publication-item.html p=p -%} {%- endfor -%} {%- endfor -%} {%- endcapture -%} {%- assign items = items | strip -%} {%- if items != "" -%}
